## 2. Термины

2.1. **Документ** — файл или текст, загруженный Пользователем в Сервис для
анализа (договор, оферта, иной документ).

2.2. **Обезличивание** — действия, в результате которых становится
невозможным без использования дополнительной информации определить
принадлежность данных конкретному субъекту персональных данных
(ст. 3 152-ФЗ). Обезличивание выполняется на устройстве Пользователя и
дополнительно проверяется на сервере.

2.3. **Вердикт** — результат автоматизированного анализа обезличенного текста
Документа: оценка рисков, пояснения и рекомендации информационного
характера, сформированные с использованием технологий искусственного
интеллекта.

## 3. Предмет договора

3.1. Исполнитель обязуется оказать Пользователю информационные услуги:

3.2. Услуги носят **информационный и справочный характер**, не являются
юридическими, бухгалтерскими или иными профессиональными услугами и не

принятия юридически значимых решений без проверки специалистом.

## 4. Порядок использования Сервиса

4.1. Пользователь загружает Документ в Сервис. Обезличивание выполняется
автоматически на устройстве Пользователя; Пользователю предоставляется
список предполагаемых замен, который он может подтвердить или изменить.

4.2. На сервер передаётся только обезличенный текст. Сервер дополнительно
проверяет текст на наличие остаточных персональных данных и при их
обнаружении автоматически до-обезличивает их.

4.3. Исходный Документ не передаётся, не хранится и не обрабатывается
Исполнителем. Обезличенный текст обрабатывается только в памяти сервера
и удаляется автоматически в течение 60 секунд после обработки.

6.1. Сервис обрабатывает только обезличенные данные, которые не являются
